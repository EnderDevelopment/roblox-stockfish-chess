# Roblox Chess Bot UI

This project contains scripts for a Roblox chess game that allows players to toggle the chess bot on and off and change the ELO setting. The chess bot uses the Stockfish chess engine to provide AI-powered moves.

## Install

1. Download the project files.
2. Place `ChessBotUI.server.lua` in the ServerScriptService.
3. Place `ChessBotUI.client.lua` in the StarterPlayerScripts.
4. Place `ChessAI.lua` in the ServerScriptService.
5. Ensure you have the Stockfish module in your ServerScriptService.

## Use

1. Run the game in Roblox Studio.
2. The chess bot UI will appear on the player's screen.
3. Click the "Toggle Bot" button to turn the chess bot on or off.
4. Use the "ELO Slider" to set the desired ELO level for the chess bot.
5. Click the "Change ELO" button to apply the new ELO setting.
